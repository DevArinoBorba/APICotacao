Como Integrar em Seus Sites (Shopify / WordPress)

Esta API possui CORS totalmente habilitado. Você pode fazer requisições diretamente do navegador dos seus clientes sem bloqueios ou criar chamadas no backend.

1. Inserir script no tema da Shopify (`theme.liquid`)

Acesse seu painel Shopify → Loja Virtual → Temas → Editar código → abra o arquivo layout/theme.liquid e cole antes de </body>:

<!-- Cotação de Moedas em Tempo Real -->
<script src="https://SUA_API_URL/static/widget.js" async></script>
<script>
  document.addEventListener('DOMContentLoaded', async function() {
    const res = await fetch('https://SUA_API_URL/api/cotacoes');
    const data = await res.json();
    console.log('Cotações carregadas:', data.cotacoes);
    // Exemplo: Salva as taxas no objeto global da loja
    window.TaxasCambio = data.cotacoes;
  });
</script>

2. Conversão Automática de Preço em Produtos

Para exibir o preço convertido nos cards de produtos ou na página de produto:

<!-- Marque qualquer elemento com data-usd para conversão automática -->
<span data-usd="{{ product.price | divided_by: 100.0 }}" class="preco-convertido">
  Calculando...
</span>

Opção A: Shortcode PHP para `functions.php` (WooCommerce ou Tema)

Adicione ao final do functions.php do seu tema filho:

// Shortcode [cotacao_dolar] no WordPress
function cotacao_dolar_shortcode() {
    $response = wp_remote_get('https://SUA_API_URL/api/cotacoes');
    if (is_wp_error($response)) return 'Cotação indisponível';
    $body = json_decode(wp_remote_retrieve_body($response), true);
    $brl = $body['cotacoes']['BRL']['compra'];
    $pyg = number_format($body['cotacoes']['PYG']['compra'], 0, ',', '.');
    $ars = number_format($body['cotacoes']['ARS']['compra'], 2, ',', '.');
    
    return "<div class='cotacao-box'>
        <span>🇺🇸 1 USD = R$ {$brl}</span> | 
        <span>₲ {$pyg}</span> | 
        <span>$ {$ars}</span>
    </div>";
}
add_shortcode('cotacao_dolar', 'cotacao_dolar_shortcode');

Opção B: Via Elementor ou Bloco HTML

Basta adicionar um bloco de código HTML em qualquer página ou rodapé com o script universal.

Barra de Cotações com 1 Linha de Código

Coloque a tag abaixo em qualquer site para criar automaticamente uma barra de cotações com atualização a cada 30 segundos:

<div id="barra-cotacoes"></div>
<script src="https://SUA_API_URL/static/widget.js" data-ticker="#barra-cotacoes" async></script>

Exemplo de requisição Fetch (CORS nativo)

// Converte 100 USD para BRL, PYG e ARS
fetch('https://SUA_API_URL/api/converter?valor=100')
  .then(res => res.json())
  .then(data => {
    console.log('Real:', data.conversoes.BRL.valor_formatado);       // R$ 513,62
    console.log('Guarani:', data.conversoes.PYG.valor_formatado);   // ₲ 571.178
    console.log('Peso Arg:', data.conversoes.ARS.valor_formatado);   // $ 151.525,00
  });
